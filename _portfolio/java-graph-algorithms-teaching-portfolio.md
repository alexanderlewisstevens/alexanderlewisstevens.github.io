[Java Graph Algorithms Teaching Portfolio](https://github.com/alexanderlewisstevens/graph-algorithms-java) is an independent, MIT-licensed project that pairs a small generic weighted-graph library with instructional materials.

The repository includes:

- deterministic breadth-first and depth-first traversals;
- Dijkstra's shortest-path algorithm with path reconstruction;
- Kruskal's minimum spanning forest with union-find;
- JUnit coverage for representation, preconditions, disconnected graphs, and boundary cases; and
- a student activity and instructor note focused on prediction, tracing, testing, accessibility, and discussion.

The project is self-directed portfolio work, not coursework or an externally accepted contribution.
