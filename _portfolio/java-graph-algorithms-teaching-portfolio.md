[Java Graph Algorithms](https://github.com/alexanderlewisstevens/graph-algorithms-java) is an MIT-licensed Java 21 project built around a generic weighted adjacency-list graph.

The repository includes:

- deterministic breadth-first and depth-first traversals;
- Dijkstra's shortest-path algorithm with path reconstruction;
- Kruskal's minimum spanning forest with union-find;
- JUnit coverage for representation, preconditions, disconnected graphs, and boundary cases; and
- a student activity and instructor note.

I wrote the code, tests, and instructional materials as an independent project.
